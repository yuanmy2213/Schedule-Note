# 测试与验收边界

业务自动化测试和原生窗口测试分别输出 JSON，业务测试也输出 JUnit XML。GitHub Release 只会在 Linux 核心、独立 Excel 读取、Windows 核心和 Windows 原生测试全部通过后生成。

## 自动化覆盖

- 标题与时间校验、两个计划时间分别可空。
- 开始、完成、撤销、补记、版本冲突、时钟回拨与审计。
- 多线程重复操作及故意使审计插入失败的事务回滚。
- 重启持久化、跨日延续、跨月归档和时区偏移。
- 软删除、恢复、排序、备份完整性、安全恢复与 30 日保留。
- 两套窗口布局和模式偏好。
- Excel ZIP/XML 结构、冻结行、可空时间、日期单元格、明细/汇总、中文/表情及公式注入。
- openpyxl 独立读取实际生成的文件。
- Windows 实际 WPF 控件事件、HWND、模式切换、尺寸恢复、窄窗口、管理页和编辑页、置顶、托盘状态与截图。

## 目标电脑验收

下列检查需要实际设备，不把 CI 通过写成这些检查已经通过：

1. Windows 11 日常运行；若使用 Windows 10，请在对应补丁版本实测。
2. 100% / 150% / 200% 缩放、两台 DPI 不同的显示器、拔插显示器后窗口可见。
3. 登录后开机启动项是否正常，移动软件目录后重新启用启动项。
4. Windows Explorer 重启、Win+D、托盘折叠区、全屏应用和系统置顶窗口。
5. 实际使用 Excel 或 WPS 打开导出文件；自动化已使用独立 OOXML 消费者验证，但不等于所有版本人工打开。
6. 企业安全软件、SmartScreen、代码签名和软件分发策略。

测试数据使用临时目录，测试不会访问生产事项数据库。手动执行原生测试时请始终提供独立的 --data-dir。
