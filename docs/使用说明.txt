今日笺 / Schedule-Note

运行：
1. 完整解压便携包，不要在 ZIP 内直接打开程序。
2. 双击 JinRiJian.exe。便携版已携带运行时；framework 版需 .NET 10 Desktop Runtime x64。
3. 软件未签名，首次启动 Windows 可能提示未知发布者。请核对下载来源和 SHA256SUMS。

每日记录：
底部输入事项并按 Enter。预计时间可在“规划今日”中填写，也可全部留空。
点击开始记录实际开始时间，点击完成记录结束时间。完成后可撤销；双击事项编辑，右键可补记、修正时间、移动、删除。

两种模式：
首次是第一版标准界面。标题栏“精简”切到紧凑模式，精简模式“⋯”切回。两边事项和时间共用，窗口大小位置分别记住。
拖动标题栏移动，拖动四边和四角调整大小。置顶可开关。标题栏右键或“⋯”可打开设置。
关闭会收起到托盘，托盘图标可唤回；托盘“退出”才真正退出。Win+D 等系统操作遵循 Windows 窗口行为。

历史与导出：
历史窗口月份输入 yyyy-MM。导出的 Excel 包含事项明细、每日汇总。事项归属月份不会因跨月完成而变动。
事项历时包含中途间隔，不等于净工作投入。

数据与备份：
数据在 %LOCALAPPDATA%\JinRiJian\daily.db，每次有效操作立即保存。
自动备份在该目录 backups 中，保留 30 个日期。设置里可手动备份、恢复；恢复前会自动保留当前数据。
已删除事项可在历史中勾选“显示已删除事项”，右键恢复。

升级：退出程序后替换解压目录中的软件文件，保留用户数据目录。便携包应保存在固定位置，再启用开机自动显示。

测试：运行包内程序时添加 --smoke-test --data-dir 临时目录 --test-report 报告路径，可运行隔离的原生窗口测试。不要指定真实使用的数据目录。
